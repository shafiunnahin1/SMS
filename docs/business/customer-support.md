## Support Ticket Priority
```
P1 — Critical (4 hour response):
  - System down / login impossible
  - Payment failed
  - Data loss

P2 — High (24 hour response):
  - Major feature not working (attendance, fee)
  - Performance severely degraded

P3 — Medium (48 hour response):
  - Minor feature issue
  - Confusing UX

P4 — Low (1 week):
  - Feature request
  - Documentation issue
```

## Institution Lifecycle Management
```
New Lead → Demo → Trial → Paid → Growth → Renewal → Expansion

Intervention points:
  - Trial day 5: No activity → Personal outreach
  - Trial day 10: Not converted → Discount offer
  - Month 3: Low usage → Training offer
  - Month 11: Approaching renewal → Annual upgrade offer
  - Churned → Win-back campaign (1 month after)
```
