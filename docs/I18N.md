# I18N — ভাষা, RTL ও আরবি (Revision 9)

> **সারকথা:** বাংলা ↔ ইংরেজি টগল সহজ। **আরবি যোগ করা শুধু আরেকটি অনুবাদ-ফাইল নয়:** আরবি ডান-থেকে-বামে (RTL), ভিন্ন লিপি ও ফন্ট, ভিন্ন শেপিং; তাই চার layout, তিন pack, আইকন, ফর্ম, চার্ট, PDF, Excel, SMS প্রভাবিত হয়। এই ফাইল সব নিয়ম একসাথে রাখে। থিম-নির্দিষ্ট RTL আচরণ `themes/theme-NN/DESIGN.md`-এর "RTL" অংশে।

> **সীমা (সততার সাথে):** (ক) আরবি অনুবাদ নিচে *খসড়া*; একজন মাতৃভাষী/মাদ্রাসা-শিক্ষকের যাচাই ছাড়া প্রকাশ নয়। (খ) PDF-এ বাংলা ও আরবির শেপিং কোন engine-এ ঠিক চলে আমি যাচাই করিনি — Spike-এ আসল রসিদ দিয়ে পরীক্ষা বাধ্যতামূলক (§৮)। (গ) RTL-এ দৃশ্যমান পরীক্ষা (Playwright) এখনো প্ল্যানে নেই; আজ শুধু স্থির lint (§৪.৫)।

## ১. ভাষা ও কে কী বাছে
| Locale | নাম (নিজ লিপিতে) | দিক | কখন চালু |
|---|---|---|---|
| `bn` | বাংলা | LTR | সব সময় (ডিফল্ট, বন্ধ করা যায় না) |
| `en` | English | LTR | ডিফল্টে চালু; প্রতিষ্ঠান বন্ধ করতে পারে |
| `ar` | العربية | **RTL** | ডিফল্টে বন্ধ; প্রতিষ্ঠান *Settings → ভাষা*-য় চালু করে, অথবা "মাদ্রাসা" প্রিসেটে (§১০) স্বয়ংক্রিয় |

- **স্তর:** (১) প্ল্যাটফর্মের সমর্থিত তালিকা (`config/i18n.php`: `bn, en, ar`), (২) প্রতিষ্ঠানের চালু-করা তালিকা `institutions.settings.locales` (+ `default_locale`), (৩) ব্যবহারকারীর ব্যক্তিগত পছন্দ `users.locale`।
- **কার্যকর ভাষা** (ক্রম): `users.locale` → (লগইনের আগে) ব্রাউজারে মনে-রাখা পছন্দ (`localStorage['locale']`) → `Accept-Language` (চালু-তালিকার ভেতরে) → `settings.default_locale` → `bn`। চালু-তালিকার বাইরের মান সবসময় বাদ।
- **Central host** (landing, signup, Super Admin): প্ল্যাটফর্মের `bn, en` (`config/i18n.php: platform_locales`); আরবি এখানে নেই।
- **টগল কোথায় (সব থিমে একই component, ভিন্ন জায়গা):**
  | থিম | অবস্থান | রূপ |
  |---|---|---|
  | theme-01 | top bar-এর ডানে + লগইন পাতার উপরে | ড্রপডাউন: "বাংলা ▾" (বর্তমান ভাষা নিজ লিপিতে) |
  | theme-02 | top bar-এ ছোট pill `বাং · EN · ع` (চালু ভাষা অনুযায়ী) + user menu-তে | segmented pill |
  | theme-03 | "আরও" পাতার উপরে + লগইনে | পূর্ণ-প্রস্থ তালিকা-সারি (≥৪৮px) |
  `LanguageSwitcher` একটি layout `parts/` component (Layout Contract-এর অংশ — `docs/THEMING.md`)। শুধু চালু ভাষাগুলো দেখায়; একটিই চালু থাকলে লুকানো। পরিবর্তন `PUT /auth/locale` (লগইন থাকলে) ও localStorage-এ; পাতা reload ছাড়াই বদলায়।

## ২. কী অনুবাদ হয়, কী হয় না
| বিষয় | অনুবাদ? | কীভাবে |
|---|---|---|
| UI লেবেল, বাটন, বার্তা | হ্যাঁ | `src/i18n/{bn,en,ar}.json` (`t('key')`) |
| প্রতিষ্ঠানের শব্দ (Class/Section/Batch/Course …) | হ্যাঁ | `config/institution_types.php` ও `institutions.terminology` — প্রতিটি `{bn,en,ar}` |
| সার্ভারের বার্তা (error, validation, notification) | হ্যাঁ | `lang/{bn,en,ar}/*.php`; `message` এখন locale অনুযায়ী (`error` কোড স্থির) |
| SMS | হ্যাঁ | প্রাপকের ভাষায় template; §৭ |
| PDF (রসিদ, marksheet, ID, সনদ) | হ্যাঁ — লেবেল | locale অনুযায়ী; engine শর্ত §৮ |
| Excel export শিরোনাম | হ্যাঁ | `lang/*/export.php`; আরবিতে sheet RTL |
| পাবলিক সাইটের কাঠামো-লেখা | হ্যাঁ | i18n; সাইটের ভাষা ডিফল্ট + টগল §৯ |
| **প্রতিষ্ঠান/ব্যবহারকারীর লেখা তথ্য** (ছাত্রের নাম, বিষয়ের নাম, নোটিশ, about, headline, বার্তা) | **না** | যেমন লেখা তেমন দেখায়; কোনো স্বয়ংক্রিয় অনুবাদ নেই |
| তারিখ/সংখ্যা/টাকার বিন্যাস | হ্যাঁ | `Intl` (§৩.৪) |
**ফলাফল:** আরবি লেবেলসহ marksheet-এ বিষয়ের নাম আরবিতে দেখাতে চাইলে বিষয়টি আরবি নামেই তৈরি করতে হবে (একটি রেকর্ডে একটি নাম)। দ্বিভাষিক নাম (`name` + `name_alt`) চাইলে আলাদা সিদ্ধান্ত (§১৫) — এখন নেই।

**Fallback চেইন** (কোনো key না থাকলে): `ar → bn → en`, `bn → en`, `en → bn`। (আরবি পাঠক এখানে বাংলাদেশি; ইংরেজির আগে বাংলা বেশি পাঠযোগ্য — অনুমান, মালিক নিশ্চিত করুন।) key-র নামই কখনো ব্যবহারকারীকে দেখানো হয় না; শেষ ভরসা `en` সংস্করণ। কভারেজ রিপোর্ট CI-তে (§১৪)।

## ৩. Frontend
### ৩.১ কাঠামো
```
frontend/src/
├── i18n/
│   ├── index.js          ← i18next init: resources bn/en/ar, fallbackLng (§২), interpolation.escapeValue=false (React escapes)
│   ├── bn.json  en.json  ar.json      ← key নামকরণ: area.thing.state  (যেমন attendance.status.present)
│   ├── locales.js        ← { bn:{dir:'ltr',label:'বাংলা'}, en:{dir:'ltr',label:'English'}, ar:{dir:'rtl',label:'العربية'} }
│   └── format.js         ← number / money / date / list formatters (§৩.৪)
├── ui/I18nProvider.jsx   ← lang + dir + font + document.title; `useLocale()`
└── components/LanguageSwitcher.jsx   (layouts/parts/ থেকে ব্যবহৃত)
```
```jsx
// ui/I18nProvider.jsx  (inside ThemeProvider; one source for lang/dir)
export function I18nProvider({ children }) {
  const { default: def, enabled } = useInstitutionStore(s => s.locales)            // from /bootstrap
  const userLocale = useAuthStore(s => s.user?.locale)
  const stored = localStorage.getItem('locale')
  const locale = [userLocale, stored, navigator.language?.slice(0, 2), def].find(l => l && enabled.includes(l)) ?? 'bn'

  useEffect(() => {
    i18n.changeLanguage(locale)
    const { dir } = LOCALES[locale]
    const root = document.documentElement
    root.lang = locale; root.dir = dir                                      // CSS (:dir, rtl: variant) and the browser's bidi key off these
    root.dataset.locale = locale                                            // tokens.css picks the font stack by [data-locale]
  }, [locale])
  return <LocaleCtx.Provider value={{ locale, dir: LOCALES[locale].dir, setLocale }}>{children}</LocaleCtx.Provider>
}
```
`useTerms()` (D5) এখন `terms[key][locale] ?? terms[key].bn ?? terms[key].en ?? key`। `t('…')` এর শূন্য-পরিস্থিতি `en`।

### ৩.২ UI লেখা — নিয়ম
- JSX-এ কোনো বাংলা/ইংরেজি/আরবি লেখা সরাসরি নয়; সব `t('…')`। (বিদ্যমান নমুনা-কোডে বাংলা literal আছে — সেগুলো উদাহরণ; নতুন কোডে `t()`। স্থির lint-নিয়ম পরে `eslint-plugin-i18next`-এর `no-literal-string`-ধাঁচের — spike-এ বাছাই; আমি সংস্করণ-বিবরণ যাচাই করিনি।)
- বাক্য কখনো টুকরো জুড়ে নয় (`t('a') + ' ' + name + t('b')`): ভাষাভেদে শব্দক্রম আলাদা। interpolation ব্যবহার: `t('absent_notice', { name, date })`।
- বহুবচন/সংখ্যা: i18next plural; আরবির ৬টি plural form আছে (zero/one/two/few/many/other) — `ar.json`-এ `_zero … _other` key লাগতে পারে; অনুবাদক জানান।
- বাক্যের ভেতরের লিঙ্গ/সম্মান-রূপ (আরবি ক্রিয়া লিঙ্গভেদী): প্রশ্নযুক্ত বার্তা নিরপেক্ষ রাখা।

### ৩.৩ দ্বিমুখী (bidi) লেখা
| উপাদান | নিয়ম |
|---|---|
| ব্যবহারকারীর লেখা নাম/বিষয়/নোটিশ | `dir="auto"` (লেখার প্রথম শক্তিশালী অক্ষর দিক ঠিক করে) + `<bdi>` যখন বাক্যের ভেতরে |
| ফোন, ইমেইল, Student ID, রসিদ নম্বর, URL, টাকার অঙ্ক | `dir="ltr"` + `unicode-bidi: isolate` (RTL বাক্যে ঘুরে না যায়) |
| ইনপুট (ফোন, ইমেইল, ID, সংখ্যা) | `dir="ltr"` + `text-start` (RTL-এ ডানে লেখা শুরু) |
| টেবিলের সংখ্যা-কলাম | অঙ্ক `dir="ltr"`, কলাম-সারিবদ্ধকরণ `text-end` |
| চার্ট | কন্টেইনার `dir="ltr"` (সময়-অক্ষ বাম→ডান থাকে); লেবেল ও শিরোনাম বর্তমান ভাষায় — পণ্য-সিদ্ধান্ত, ডিফল্ট এটি |
`<bdi>`-ওয়ালা `PlainText`, `Ltr` ছোট component `components/bidi/` থেকে নিন।

### ৩.৪ সংখ্যা, টাকা, তারিখ (`i18n/format.js`)
```js
const TAG = { bn: 'bn-BD-u-nu-latn', en: 'en-BD', ar: 'ar-u-nu-latn' }       // -u-nu-latn = Latin digits 0-9 in every language
export const fmtNumber = (n, l) => new Intl.NumberFormat(TAG[l]).format(n)
export const fmtMoney  = (n, l) => '৳' + new Intl.NumberFormat(TAG[l], { minimumFractionDigits: 0, maximumFractionDigits: 2 }).format(n)
export const fmtDate   = (d, l) => new Intl.DateTimeFormat(TAG[l], { dateStyle: 'medium', timeZone: 'Asia/Dhaka' }).format(new Date(d))
```
- **সংখ্যার লিপি:** সব ভাষায় ডিফল্ট Latin অঙ্ক (০–৯ নয়, ٠–٩ নয়) — টাকা/ID/রসিদে অস্পষ্টতা এড়াতে। বাংলা বা আরবি অঙ্ক চাইলে `settings.digits = native` (এখনো বানানো নেই; খোলা সিদ্ধান্ত §১৫, `docs/DESIGN-SYSTEM.md` §৮)।
- **ক্যালেন্ডার:** শুধু গ্রেগরিয়ান। হিজরি তারিখ মাদ্রাসায় চাওয়া হতে পারে — **এই ফাইলে নেই**, আলাদা সিদ্ধান্ত (§১০.৩)।
- ব্রাউজারের `Intl` সমর্থন (বিশেষত `bn-BD`, `-u-nu-latn`) পুরনো Android WebView-এ সীমিত হতে পারে — Spike-এ ৩টি ডিভাইসে যাচাই।

## ৪. RTL
### ৪.১ নিয়ম
1. **শুধু logical property।** `ms-* me-* ps-* pe-* start-* end-* text-start text-end rounded-s-* rounded-e-* border-s border-e` (Tailwind ≥ 3.3)। `ml-* mr-* pl-* pr-* left-* right-* text-left text-right rounded-l* rounded-r* border-l* border-r* space-x-* divide-x float-left/right` **নিষেধ** (lint `physical-direction`)।
2. ব্যবধানে `gap-*` (flex/grid), `space-x-*` নয়।
3. **দিক-সূচক আইকন** (`ChevronLeft/Right`, `ArrowLeft/Right`, `ChevronsLeft/Right`, `Undo/Redo`, "পরবর্তী/পূর্ববর্তী" তীর) সরাসরি import নিষেধ; `<DirIcon icon={ChevronRight} />` ব্যবহার (RTL-এ `rtl:-scale-x-100`)। অ-দিক আইকন (খুঁজুন, ঘণ্টা, গিয়ার) আয়না হয় না। lint `directional-icon`।
4. Absolute/transform: `inset-inline-start`, `start-0`; `translate-x` দরকার হলে `rtl:` সহ জোড়া।
5. স্ক্রল/ড্র্যাগ দিক: carousel/kanban/stepper-এ `dir`-সচেতন; কীবোর্ড ← → অর্থ `dir` দেখে (RTL-এ → হলো "আগের")।
6. ছবি/লোগো আয়না হয় না। সংখ্যা-ফ্লো (পেজিনেশন "১ ২ ৩") RTL-এ ডান থেকে বাম বাড়ে (স্বাভাবিক)।
7. `@media print` ও PDF: `dir` লেখার ভাষা অনুযায়ী (§৮)।

| `mobile-compact` | tab bar-এ ক্রম আয়না (হোম ডানে); FAB inline-end (বামে); "পিছনে" তীর আয়না; bottom sheet প্রতিসম |

| `list=cards/table` | কলাম-ক্রম আয়না (প্রথম কলাম ডানে); `primary` কলাম ডানে |
| `leads.board` কানবান | কলাম ডান→বাম; ড্র্যাগ-নির্দেশক আয়না |
| `attendance.take` segmented | বিকল্প-ক্রম আয়না (যে ক্রম লেখা সেই ক্রমে পড়া) |
| বাটন-জোড়া (বাতিল / সংরক্ষণ) | primary ক্রিয়া inline-end-এ (RTL-এ বামে) — layout নিজে থেকে `flex` দিয়ে |
| `ThemeEditor` পূর্বরূপ | `dir` সহ পূর্বরূপ (নিজের ভাষায়), আলাদা "RTL দেখুন" টগল |
এগুলো প্রতিটি `UI Pack`-এর `ComponentVariantContractTest`-এ `dir=rtl` রূপে চলবে (§১৪)।

### ৪.৩ Layout Contract-এ যোগ
(`docs/THEMING.md`) প্রতিটি layout: (ক) physical class নেই, (খ) `LanguageSwitcher` দেখায়, (গ) `dir=rtl`-এ চারটি স্ক্রিন-আকারে ফিট করে, (ঘ) `DirIcon` ব্যবহার।

### ৪.৪ ফন্ট (লিপি অনুযায়ী)

## ৬. Backend
```php
// config/i18n.php
return [
    'supported'        => ['bn', 'en', 'ar'],
    'platform_locales' => ['bn', 'en'],                      // central host
    'dir'              => ['bn' => 'ltr', 'en' => 'ltr', 'ar' => 'rtl'],
    'fallback'         => ['ar' => ['bn', 'en'], 'bn' => ['en'], 'en' => ['bn']],
];

// app/Http/Middleware/SetLocale.php  - after `tenant` and `auth:sanctum` (so the user is known); on tenant-optional routes it runs without a user
public function handle($request, Closure $next)
{
    $inst    = \App\Support\Tenancy::current();
    $enabled = $inst ? ($inst->settings['locales'] ?? ['bn', 'en']) : config('i18n.platform_locales');
    $default = $inst ? ($inst->settings['default_locale'] ?? 'bn') : 'bn';

    $locale = collect([$request->user()?->locale, $this->fromHeader($request)])->first(fn ($l) => $l && in_array($l, $enabled, true)) ?? $default;
    app()->setLocale($locale);
    return tap($next($request), fn ($res) => $res->headers->set('Content-Language', $locale));
}
```
- `lang/{bn,en,ar}/{messages,validation,errors,export,sms,pdf}.php`। Validation বার্তার জন্য সাধারণত community প্যাকেজ (যেমন `laravel-lang/lang`) — `bn`, `ar` কভারেজ **যাচাই করুন**।
- API error: `error` কোড স্থির; `message = __("errors.{$code}")`। `BusinessException` এখন key নেয় (`new BusinessException('errors.holiday_date')`), বাংলা literal নয়। বিদ্যমান নমুনা-কোডের বাংলা literal গুলো সেই পুনর্লিখনের তালিকা (প্রতি Step-এ ছুঁলে বদলান)।
- `term($key, $locale)`: `terminology[$key][$l] ?? config terms[$key][$l] ?? fallback চেইন ?? $key`।
- `users.locale VARCHAR(5) NULL` (ENUM নয় — নতুন ভাষা যোগে migration নয়, D24-র নীতি)। **নোট:** `docs/architecture/system-design-patterns.md`-এ আগে `ENUM('bn','en')` লেখা মন্তব্য ছিল, স্কিমায় কলাম ছিলই না — এখন `schema.sql`-এ।

## ৭. SMS — ভাষা, এনকোডিং, খরচ
**ভাষা:** SMS প্রাপকের ভাষায়: অভিভাবক-user থাকলে `users.locale`, নইলে `settings.sms_locale ?? default_locale`। Template `lang/*/sms.php`। কলার `__('sms.absent', [...], $locale)` দিয়ে বার্তা বানিয়ে `SendSmsJob`-এ দেয় (job শুধু বহন করে)।

**সমস্যা (আরবির আগেই বাংলায় বিদ্যমান):** বাংলা ও আরবি GSM-7 অক্ষরে নেই, তাই SMS **Unicode (UCS-2)** — একক বার্তা ৭০ অক্ষর (GSM-7-এর ১৬০-এর বদলে), জোড়া-বার্তায় প্রতি অংশ ৬৭ (GSM-এ ১৫৩)। আগের স্পেক প্রতি SMS ১টি ধরত (`chargeOne`) — দীর্ঘ বার্তায় gateway-র খরচের চেয়ে কম গণনা হতো।
```php
// app/Support/SmsSegments.php  - the ALGORITHM was checked in a reference implementation on 16 boundary cases (GSM 03.38 basic + extension table; UCS-2 otherwise);
// this PHP port is not run - SmsSegmentsTest must reproduce the same 16 cases
final class SmsSegments
{
    private const GSM = "@£\$¥èéùìòÇ\nØø\rÅåΔ_ΦΓΛΩΠΨΣΘΞ\x1bÆæßÉ !\"#¤%&'()*+,-./0123456789:;<=>?¡ABCDEFGHIJKLMNOPQRSTUVWXYZÄÖÑÜ§¿abcdefghijklmnopqrstuvwxyzäöñüà";
    private const EXT = "^{}\\[~]|€\f";                                       // each counts 2 in GSM-7

    /** @return array{segments:int, encoding:'gsm'|'unicode', units:int} */
    public static function count(string $text): array
    {
        if ($text === '') return ['segments' => 0, 'encoding' => 'gsm', 'units' => 0];
        $chars = mb_str_split($text);
        $gsm = collect($chars)->every(fn ($c) => str_contains(self::GSM, $c) || str_contains(self::EXT, $c));
        if ($gsm) {
            $units = collect($chars)->sum(fn ($c) => str_contains(self::EXT, $c) ? 2 : 1);
            return ['segments' => $units <= 160 ? 1 : (int) ceil($units / 153), 'encoding' => 'gsm', 'units' => $units];
        }
        $units = (int) (strlen(mb_convert_encoding($text, 'UTF-16LE', 'UTF-8')) / 2);       // UTF-16 code units (an emoji = 2)
        return ['segments' => $units <= 70 ? 1 : (int) ceil($units / 67), 'encoding' => 'unicode', 'units' => $units];
    }
}
```
- `SmsService::send()`: বার্তা গঠনের পর `SmsSegments::count()`; quota/credit **segments** অনুযায়ী (`chargeOne($i)` → `charge($i, $segments)`); `sms_logs.segments`, `sms_logs.encoding` সংরক্ষণ। ব্যবহারকারীকে SMS পাঠানোর আগে "অক্ষর/অংশ" দেখানো (bulk SMS পাতায় লাইভ কাউন্টার)।
- **প্রতিষ্ঠানের নামের suffix খরচ দ্বিগুণ করতে পারে — মাপা:** হাজিরার এক-লাইন SMS একা: বাংলা ১ অংশ (৬৬ ইউনিট), আরবি ১ (৫৮), ইংরেজি ১। প্ল্যাটফর্ম-sender-এর `-প্রতিষ্ঠানের নাম` যোগে: **বাংলা ২ অংশ (৮৭), আরবি ২ (৭৭)**, ইংরেজি ১ (৭৮, GSM)। অতএব (ক) নিজস্ব approved sender ID (suffix লাগে না) বাংলা/আরবি প্রতিষ্ঠানের জন্য সরাসরি আর্থিক সুবিধা; (খ) `settings.sms_short_name` ছোট রাখার পরামর্শ (≤ ১০ অক্ষর) UI-তে।
- **Gateway এনকোডিং প্যারামিটার (unicode ফ্ল্যাগ/ফিল্ড):** SSL Wireless API-তে কী লাগে আমি যাচাই করিনি → `TODO(OD-sms-unicode)`; `SmsService::post()` এ placeholder ও sandbox-এ বাংলা + আরবি SMS পরীক্ষা Spike-এর Done-When।
- **D56 (মালিক, 2026-10-10) — দাম:** প্রতিষ্ঠানের ওয়ালেট টাকায়; প্রতি **বিলযোগ্য অংশ** প্ল্যাটফর্ম-হার (০.৪০ টাকা)। বিলযোগ্য অংশ: GSM (ইংরেজি) প্রতি ১৫০ অক্ষরে ১ (`ceil(units/150)`), Unicode (বাংলা) উপরের মতো ৭০ / ৬৭। `SmsSegments::count()` gateway-র কারিগরি গণনা (১৬০/১৫৩) অপরিবর্তিত থাকে (`sms_logs.segments`); দাম `SmsSegments::billable()` থেকে (`sms_logs.cost`)। প্রতিষ্ঠানের নিজস্ব API-তে (D59) কোনো টাকা কাটে না। মাসিক plan-কোটা আর নেই (D55)।
- মিশ্র-লিপি সতর্কতা: ইংরেজি বার্তায় একটি বাংলা/আরবি অক্ষর ঢুকলে পুরো SMS Unicode হয়ে যায় (খরচ বাড়ে) — template-এ ভাষা মেশানো নিষেধ; প্রাপকের নাম বাংলা হলে ইংরেজি SMS-এও তা Unicode করে — `SmsSegments` এটি দেখায়।

## ৮. PDF ও Excel

- ফলাফল `docs/DECISIONS.md`-এ; তারপর `docs/modules/pdf-reports.md` সংশোধন। ফলের আগে PDF-এর ভাষা-বিন্যাস চূড়ান্ত নয়।
- PDF-এর ভাষা = অনুরোধকারী/প্রাপকের locale (রসিদ: অভিভাবকের; marksheet: প্রতিষ্ঠানের `default_locale` বা `?lang=`); `<html lang dir>` Blade-এ।
- **Excel** (Maatwebsite/PhpSpreadsheet): শিরোনাম `__('export.*')`; আরবি locale-এ `$sheet->setRightToLeft(true)` (**সংস্করণে যাচাই করুন**); কলামের ফন্ট-পরিবার ম্যাক্সিমাম Unicode-সক্ষম (Calibri/Arial) — Noto নয় (পাঠকের পিসিতে নেই)।

হিজরি তারিখ-প্রদর্শন ও ইসলামি ছুটি-ক্যালেন্ডার · হিফজ/তিলাওয়াত অগ্রগতি-ট্র্যাকিং · কওমি বোর্ডের গ্রেড-লেবেল (যেমন মুমতাজ/জায়্যিদ জিদ্দান …; `settings.grading_scale`-এ সারি-ভিত্তিক লেবেল যোগ করা সম্ভব, আরবি লেবেলসহ — স্কেলের সংখ্যা মাদ্রাসা বোর্ড ঠিক করে, আমি যাচাই করিনি) · আলিয়া/দাখিল/আলিম বোর্ডের নিবন্ধন-তথ্য · আরবি/বাংলা দ্বিভাষিক নাম-ক্ষেত্র · নামাজের সময়সূচি-ভিত্তিক রুটিন।

## ১১. ডেটা-পরিবর্তন
| কোথায় | কী | নোট |
|---|---|---|
| `users` | `locale VARCHAR(5) NULL` | VARCHAR |
| `institutions.settings` (JSON) | `locales`, `default_locale`, `sms_locale`, `terminology_preset`, `sms_short_name` | কলাম নয়; bootstrap পাবলিক তালিকায় `locales`, `default_locale` |
| `institutions.terminology` (JSON) | প্রতিটি key-র `{bn,en,ar}` | বিদ্যমান |
| `sms_logs` | `segments TINYINT UNSIGNED NOT NULL DEFAULT 1`, `encoding VARCHAR(10) NOT NULL DEFAULT 'gsm'` | খরচ-হিসাব |
`docs/database/schema.sql`-এ প্রয়োগ করা হয়েছে (users.locale, sms_logs.segments/encoding)।

## ১২. API
```
PUT  /auth/locale                      { locale }                       any authenticated user; locale must be in the institution's enabled list
GET  /admin/settings/language          → { enabled[], default, sms_locale, terminology_preset, available_presets[] }
PUT  /admin/settings/language          → { enabled[] (bn always), default, sms_locale }                        [admin]
POST /admin/settings/terminology-preset { preset: 'madrasa' | null }                                           [admin; replaces terminology, asks confirmation]
GET  /bootstrap                        → …, locales:{ default, enabled, dir:{bn:'ltr',…} }
```
`Accept-Language` সব অনুরোধে axios interceptor পাঠায় (`store.locale`); সার্ভার উত্তরে `Content-Language`।

## ১৩. অনুবাদ-প্রক্রিয়া ও মান
