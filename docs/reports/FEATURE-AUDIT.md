# Feature Audit — Revision 6.3

## Method
পুরনো আপলোড (Revision 5, `school-saas-complete-plan.zip`) থেকে সব টেবিল, কলাম, route, endpoint, ফাইল ও ৫০টি ফিচার বের করে বর্তমান প্ল্যানের সাথে স্ক্রিপ্টে মেলানো হয়েছে; তারপর আপনার চাওয়া ও চার ধরনের প্রতিষ্ঠানের প্রয়োজনে যা কখনো প্ল্যানে ছিল না তা আলাদা খোঁজা হয়েছে।
**সীমা:** স্ক্রিপ্ট keyword/নাম মেলায়, কোড চালায় না। MySQL/PHP/Node এই পরিবেশে নেই।

## 4. প্ল্যানে কখনোই ছিল না — আপনার হ্যাঁ/না লাগবে
এগুলো "বাদ পড়া" নয়; পুরনো প্ল্যানেও ছিল না। আপনার চার ধরনের প্রতিষ্ঠানে কতটা দরকার তার ভিত্তিতে সুপারিশ।

### স্তর ১ — একাডেমিক ফলাফলের জন্য প্রায় অপরিহার্য (school/college), সুপারিশ: যোগ করুন
| ফিচার | কেন দরকার |
|---|---|
| **সমন্বিত/ওজনযুক্ত ফাইনাল ফলাফল** (যেমন ১ম সাময়িক ৩০% + ২য় সাময়িক ৩০% + বার্ষিক ৪০%) | বাংলাদেশের বেশিরভাগ স্কুল-কলেজ বছরের ফলাফল একাধিক পরীক্ষা মিলিয়ে দেয়; এখন শুধু আলাদা পরীক্ষার ফল আছে |
| **Tabulation Sheet** (সব ছাত্র × সব বিষয় এক পাতায়, প্রিন্টযোগ্য) | শিক্ষকরা এটিই ছাপিয়ে ফল যাচাই ও সংরক্ষণ করেন; উপরের ফিচারের উপর নির্ভরশীল |

### স্তর ২ — দৈনন্দিন কাজ, সুপারিশ: যোগ করুন
| ফিচার | অবস্থা |
|---|---|
| **অশিক্ষক কর্মচারীর বেতন** (হিসাবরক্ষক, অফিস সহকারী, দারোয়ান) | HR শুধু `teachers` টেবিলে (`salary_payments.teacher_id`); Accountant ব্যবহারকারী আছে কিন্তু তার বেতনের ঘর নেই |
| **অভিভাবকের ছুটির আবেদন** (সন্তানের অনুপস্থিতি) | Parent panel-এ নেই; `leave_applications` শুধু কর্মীদের |
| **বকেয়া থাকলে Admit Card/ফলাফল আটকানো** (প্রতিষ্ঠান চালু/বন্ধ করতে পারবে) | নেই; অনেক প্রতিষ্ঠান চায় |
| **দৈনিক কালেকশন / ক্যাশবুক রিপোর্ট** | Accountant panel-এ স্পষ্ট নেই |
| **বদলি শিক্ষক** (অনুপস্থিত শিক্ষকের ক্লাসে) | নেই |

### স্তর ৩ — SaaS ব্যবসার জন্য (আপনার দিক)
| ফিচার | অবস্থা |
|---|---|
| **প্রতিষ্ঠান → আপনার কাছে Support Ticket** (অ্যাপের ভেতরে) | শুধু ব্যবসায়িক নথি (`customer-support.md`), অ্যাপে নেই |
