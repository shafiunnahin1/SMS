| D22 | Public site | প্রতিটি প্রতিষ্ঠানের ছোট পাবলিক সাইট (Home, Notices, Admission) + ভর্তি-আবেদন → `admission_leads`; SEO shell Laravel দেয়, `/`, `/notices`, `/admission`, `robots.txt`, `sitemap.xml` Nginx থেকে সরাসরি Laravel-এ (rewrite নয়); `/bootstrap` শুধু allow-listed settings পাঠায়। `docs/modules/public-website.md` |

## Which File Wins When Two Disagree
1. `AGENTS.md` (working rules) and this file (decisions)
2. `docs/modules/*`, `docs/THEMING.md`, `docs/modules/custom-domain.md`
3. `docs/database/schema.sql` (database-এর জন্য)
4. যে ফাইলে "(Revision 6)" চিহ্নিত section আছে, সেই section
5. বাকি সব ফাইল

পুরনো module ফাইলগুলো (`docs/modules/*`, `docs/templates/*` ইত্যাদি) স্কুলের প্রেক্ষাপটে লেখা হয়েছিল; সেগুলোর identifier ইতিমধ্যে নতুন নামে বদলানো আছে, কিন্তু গদ্যে "স্কুল", "ক্লাস", "সেকশন" শব্দ থাকতে পারে — সেগুলো যথাক্রমে institution, program, batch বোঝায়।
