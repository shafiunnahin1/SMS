# theme-03 — Design (Tutor Lite)

> বেসলাইন `themes/theme-01/DESIGN.md`। এখানে পার্থক্য।
>
> **কোনটি কখন আসে:** রঙ, ২০px radius, `spacious` ঘনত্ব, নিচের tab bar, `max-w-md` = পর্যায় A; bottom-sheet মোডাল, কার্ড-তালিকা, compact StatCard = পর্যায় B (component variant); নিচের "পাতার ধরন" সারণির বিশেষ সাজ (segmented হাজিরা, FAB, দ্রুত-ভর্তি sheet, এক-কলাম ফি-আদায়, "আজকের কাজ" হোম) = **পর্যায় C, মালিকের অনুমোদনে**। তার আগে ওই কাজগুলো বেসলাইন view-তে ফোনেও চলে, তবে কম অপ্টিমাইজড। বিস্তারিত: `docs/UI-PACKS.md` §১০।

## অনুভূতি
বন্ধুত্বপূর্ণ, বড়, গোল (২০px radius)। বেগুনি + কমলা আবেগী, তবে কনটেন্ট পরিষ্কার সাদা। ফোনে এক হাতে, ক্লাসের ফাঁকে, তাড়াহুড়োয় কাজ — তাই **পাতাপ্রতি একটি কাজ**, বড় লক্ষ্য, কম পড়া।

## কাঠামো (৩৯০px)
```
┌──────────────────────────────┐
│ রহিম স্যারের গণিত ব্যাচ   🔔 │ ← সরু শিরোনাম-বার (৫৬px)
├──────────────────────────────┤
│ আজ, শনিবার                    │
│ ┌ ৫ ছাত্র ┐┌ ৳২,৪০০ ┐┌ ২ বাকি┐│ ← compact StatCard সারি (অনুভূমিক scroll নয়, ৩টি)
│ ╭───────────────────────────╮ │
│ │ Class 9 সকাল ·  ৭:০০–৮:০০ │ │ ← "আজকের ব্যাচ" কার্ড
│ │ ৫ জন · [ হাজিরা নিন ▸ ]   │ │   বড় বাটন, বুড়ো আঙুলের নাগালে
│ ╰───────────────────────────╯ │
│ বকেয়া (২)              সব ▸  │
│  রাফি — ৳৮০০    [SMS] [আদায়]  │
│  তানিয়া — ৳৮০০ [SMS] [আদায়]  │
├──────────────────────────────┤
│  🏠      📚      👥     ৳   ⋯ │ ← tab bar (৬৪px + safe-area)
│ হোম   ব্যাচ  ছাত্র   ফি  আরও │

```
Tab bar-এর ৪ প্রধান = `primary: true` আইটেম (`docs/AUTHORIZATION.md` মেনু: Home, Batches, Students, Fees)। বাকি সব "আরও" পাতায় (পরীক্ষা, SMS, খরচ, রিপোর্ট, সেটিংস, সাবস্ক্রিপশন)।

## পাতার ধরন (পার্থক্য)
| ধরন | নকশা |
|---|---|
| হোম | একক কলাম; উপরে ৩টি compact StatCard; "আজকের ব্যাচ" (`batches.schedule` থেকে) কার্ড-সারি; "বকেয়া" দ্রুত-তালিকা (নাম, অঙ্ক, [SMS] [আদায়]); "সব বকেয়াকে SMS" বাটন |
| হাজিরা | ব্যাচ বেছে (বা হোম থেকে সরাসরি) **পূর্ণ-পর্দা তালিকা**: প্রতি ছাত্রের সারিতে বড় সেগমেন্ট `উপস্থিত | অনুপস্থিত | দেরি`; উপরে "সবাই উপস্থিত"; নিচে স্থির "সংরক্ষণ" বাটন (tab bar-এর ঠিক উপরে) |
| ছাত্র-তালিকা | খোঁজা + batch ফিল্টার (chip); সারি = কার্ড (নাম, batch, ফি-অবস্থা); ট্যাপ → প্রোফাইল। **টেবিল নয়** |
| দ্রুত ভর্তি | **bottom sheet** (নিচ থেকে ওঠে): নাম, অভিভাবকের ফোন, batch — তিনটি ঘর, বড় "যোগ করুন"; ঐচ্ছিক বাকি তথ্য পরে |
| ফি আদায় | মাস বেছে → paid/unpaid তালিকা; সারিতে এক ট্যাপে "আদায়" → নিশ্চিতকরণ sheet (অঙ্ক, পদ্ধতি cash) → রসিদ + SMS বিকল্প |
| পরীক্ষা (ছোট টেস্ট) | নম্বর-এন্ট্রি: ছাত্র-প্রতি একটি সংখ্যা-ঘর (`inputmode="decimal"`), "পরবর্তী" কীবোর্ড-অ্যাকশন পরের ঘরে যায় |
| লগইন | `centered`; ফোন-নম্বর ইনপুট (`inputmode="tel"`), পাসওয়ার্ড; লোগো উপরে |

## আচরণ-নিয়ম
- **বুড়ো আঙুলের অঞ্চল:** প্রধান ক্রিয়া পর্দার নিচের অর্ধেকে (স্থির বাটন বা sheet-এর ভেতরে); শিরোনাম-বারে শুধু গৌণ ক্রিয়া।
- **Hover-নির্ভর কিছু নয়:** টুলটিপ নেই; সব তথ্য দৃশ্যমান বা ট্যাপে।
- **সোয়াইপ-একা ক্রিয়া নয়:** সোয়াইপ থাকলেও প্রতিটির বাটন-বিকল্প আছে (অ্যাক্সেসিবিলিটি)।
- **Bottom sheet:** ফোকাস-ট্র্যাপ, Esc/পিছনে-বোতামে বন্ধ, drag-handle দৃশ্যমান, কীবোর্ড ওঠলে sheet উপরে সরে।
- **সংরক্ষণ-ভরসা:** সংরক্ষণের পরে স্পষ্ট নিশ্চিতকরণ ("৫ জনের হাজিরা সংরক্ষিত") ও শেষ-পূর্বাবস্থা (Undo ১০ সেকেন্ড)।
- **অফলাইন:** এই release-এ নেই (PWA Phase 10); সংযোগ নেই হলে স্পষ্ট বার্তা ও পুনরায় চেষ্টা, নীরবে ব্যর্থ নয়।
- **ডেস্কটপ:** ৪৮০px কলাম কেন্দ্রে, দুই পাশে `bg-surface-muted`। বড় পর্দায় আলাদা ডেস্কটপ-নকশা নেই (ইচ্ছাকৃত) — ডেস্কটপ-কেন্দ্রিক কাজ হলে `theme-02`/`theme-01`।

## Dark mode
জমিন `#0F172A`; tab bar `#1E293B`; সক্রিয় আইকন+লেবেল `text-primary-fg` (`#CBB0F8`, 6.57:1)। সেগমেন্ট-নিয়ন্ত্রণের নির্বাচিত অংশ `bg-primary text-on-primary`।

## করবেন না
- ৫-র বেশি tab; লেবেল-ছাড়া আইকন tab।
- ছোট (<৪৪px) লিঙ্ক/আইকন-বাটন; ১৬px-এর নিচে ইনপুট।
- ছাত্র-তালিকায় অনুভূমিক-scroll টেবিল।
- accent-কমলায় সাদা লেখা (২.৮০:১)।
- পূর্ণ-পর্দা কেন্দ্রীয় modal (sheet ব্যবহার করুন; সহজে হাতের নাগালে বন্ধ হয়)।

## ভাষা ও RTL (Revision 9 — `docs/I18N.md`)
- **টগল:** "আরও" পাতার উপরে পূর্ণ-প্রস্থ সারি (≥৪৮px), বর্তমান ভাষা চিহ্নিত; লগইন পাতার উপরে ছোট বাটন। Tab bar-এ ভাষা-বাটন নেই (জায়গা বাঁচাতে)।
- **RTL (আরবি):** tab bar-এর ক্রম আয়না (হোম **ডানে**); "পিছনে" তীর `DirIcon` (ডানমুখী); FAB inline-end-এ (বামে); segmented হাজিরা `উপস্থিত | অনুপস্থিত | দেরি` ক্রম আয়না (প্রথম বিকল্প ডানে); bottom sheet প্রতিসম; চার্ট `dir="ltr"`।
- নিচের tab bar ও সব বাটন ≥৪৮px RTL-এও; আরবির ১৭px ফন্টে লেবেল ছোট tab-এ কাটে কিনা ৩৬০px-এ যাচাই (লেবেল ছোট করা বা ২ লাইন)।
