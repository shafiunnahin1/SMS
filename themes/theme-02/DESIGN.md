# theme-02 — Design (Modern Mint)

> বেসলাইন `themes/theme-01/DESIGN.md`। এখানে শুধু পার্থক্য।
>
> **কোনটি কখন আসে:** রঙ, ছায়া-কার্ড, ১৪px radius, আইকন-রেল/flyout, batch-সুইচার = পর্যায় A; pill-ট্যাব ও আইকন-গোল StatCard = পর্যায় B (UI Pack-এর component variant); নিচের "পাতার ধরন" সারণি (আজকের-batch ড্যাশবোর্ড, দ্রুত-ভর্তি, কানবান লিড) = **পর্যায় C, মালিকের অনুমোদনে** — তার আগে সেই পাতাগুলো বেসলাইন view-তে চলে। বিস্তারিত: `docs/UI-PACKS.md` §১০, `COMPONENTS.md`-এর স্তর-সারণি।

## অনুভূতি
হালকা, গোলগাল, তরতাজা। বড় radius (১৪px), সীমার বদলে নরম ছায়া, টিল ও অ্যাম্বার। কম "অফিস", বেশি "অ্যাপ"। তবুও তথ্যঘন — সৌন্দর্যের জন্য ঘনত্ব কমানো হয়নি (`density=comfortable`)।

## কাঠামো
```
┌──┬───────────────────────────────────────────────────────────┐
│◉ │  আজকের ব্যাচ ▾           🔍 খুঁজুন      🔔  ☀/☾  👤       │
│👥│───────────────────────────────────────────────────────────│
│📚│  ╭─────────╮ ╭─────────╮ ╭─────────╮ ╭─────────╮          │
│✓ │  │আজ ভর্তি│ │ বকেয়া  │ │ হাজিরা │ │ নতুন লিড│  ← ছায়া-কার্ড│
│৳ │  ╰─────────╯ ╰─────────╯ ╰─────────╯ ╰─────────╯          │
│✉ │  ╭────────────────────────────────────────────────────╮   │
│⚙ │  │  ব্যাচ-তালিকা / ফি আদায় …                          │   │
│  │  ╰────────────────────────────────────────────────────╯   │
└──┴───────────────────────────────────────────────────────────┘
 ৭২px         কনটেন্ট — বেশি প্রস্থ
```
- **রেল:** আইকন ২৪px কেন্দ্রে; লেবেল নেই। hover/ফোকাসে ডানে flyout (গ্রুপ-নাম + উপ-মেনু), ২০০ms। সক্রিয় = `bg-primary-soft` গোল-বর্গ + আইকন `text-primary-fg`। রেলের নিচে ব্যবহারকারী-অবতার।
- **টুল-বার:** বাম প্রান্তে **batch-সুইচার** (আজ কোন ব্যাচ দেখছেন — কোচিংয়ের প্রধান প্রসঙ্গ), মাঝখানে গ্লোবাল খোঁজা (ছাত্র নাম/ফোন/ID), ডানে নোটিফিকেশন, mode, ব্যবহারকারী।
- **কীবোর্ড:** রেলে `Tab` আইকন-থেকে-আইকন; `Enter`/`→` flyout খোলে; `Esc` বন্ধ করে ও ফোকাস রেলে ফেরায়। flyout শুধু hover-নির্ভর নয়।

## পাতার ধরন (পার্থক্য)
| ধরন | নকশা |
|---|---|
| ড্যাশবোর্ড | StatCard-এ বামে-দাগের বদলে আইকন-গোল (primary-soft ব্যাকগ্রাউন্ড); "আজকের ব্যাচ" কার্ড (সময়সূচি অনুযায়ী) ও "বকেয়া" দ্রুত-তালিকা — এক ট্যাপে SMS |
| ছাত্র-ভর্তি (দ্রুত) | ছোট ৩-ঘরের ফর্ম (নাম, অভিভাবকের ফোন, batch) প্রথমে; "বিস্তারিত যোগ করুন" ভাঁজ-করা। রিসেপশনের গতির জন্য |
| ফি আদায় | বকেয়ার চেকবক্সের পাশে প্রতি batch-এর রঙিন-নয়, **লেবেলযুক্ত** ট্যাগ (দুই batch-এর ফি আলাদা সারিতে); ডানে সারাংশ ও "একটি রসিদ" |
| হাজিরা | batch-ভিত্তিক গ্রিড; বড় টগল (Present/Absent/Late); "সবাই উপস্থিত" শর্টকাট; শেষে "অনুপস্থিতদের SMS" |
| Lead (আবেদন) | কানবান-ধাঁচ কলাম (নতুন / যোগাযোগ / ভিজিট / ভর্তি) — মাউস ছাড়াও কীবোর্ডে সরানো যায় |

## Dark mode — বিশেষ যত্ন
`shadow` কার্ড কালো জমিনে অদৃশ্য। তাই `.dark`-এ `--card-border: 1px solid var(--line)`, `--card-shadow: none` (`TOKENS.md` §৪)। অন্যথায় কার্ডগুলো মিলিয়ে যায়।

## মোবাইল (<১০২৪px)
রেল → drawer (পূর্ণ লেবেলসহ মেনু); batch-সুইচার top bar-এ থাকে; টেবিল কার্ড-তালিকায় রূপান্তর ঐচ্ছিক নয় — অনুভূমিক scroll। হাজিরা ও ফি আদায় ৩৬০px-এ ব্যবহারযোগ্য হতে হবে (কোচিং-মালিক ফোনেও করেন)।

## করবেন না
- রেলে লেবেল-ছাড়া নতুন আইকন (প্রতিটির `aria-label` ও tooltip আবশ্যক)।
- flyout-এ ২ স্তরের বেশি।
- সীমা ও ছায়া একসাথে (হয় একটি; `card_style` token-ই ঠিক করে)।
- accent-অ্যাম্বারে সাদা লেখা (২.১৫:১)।

## ভাষা ও RTL (Revision 9 — `docs/I18N.md`)
- **টগল:** top bar-এ ছোট pill `বাং · EN · ع` (শুধু চালু ভাষা) + user menu-তে; ছোট পর্দায় user menu-র ভেতরে।
- **RTL (আরবি):** আইকন-রেল **ডানে**; flyout **বামে** খোলে; কীবোর্ডে → মানে "পিছনে", ← মানে "সামনে/flyout খোলা" (রেল ডানে বলে); batch-সুইচার top bar-এর ডান প্রান্তে; pill-ট্যাবের ক্রম আয়না; কানবান কলাম ডান→বাম; ছায়া-কার্ড দিক-নিরপেক্ষ।
- Tooltip/flyout `inset-inline-*` দিয়ে; হার্ডকোড `left`/`right` নয়।
- ফন্ট: `anek-bangla` বাংলা/ল্যাটিনের জন্য; আরবি হরফে Noto Sans Arabic (Anek Bangla-তে আরবি নেই)।
