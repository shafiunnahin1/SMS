# ইমেইল ম্যানেজমেন্ট — মালিকের কথা (চ্যাট, 2026-10-11) — স্পেক লেখার আগের নোট

> স্পেক নয়, সিদ্ধান্ত নয়। মালিকের প্রয়োজন হুবহু; মডিউল-স্পেক ও সিদ্ধান্ত-সারি পরে।

## যা বলা হয়েছে
- প্রতিষ্ঠানের যদি **নিজস্ব ডোমেইন** ও **ডোমেইন-ভিত্তিক বিজনেস ইমেইল** থাকে, তাহলে প্ল্যাটফর্মে **ইমেইল ম্যানেজমেন্ট** থাকবে: **নতুন ইমেইল-ঠিকানা খোলা**, **ইমেইল পাঠানো** — "সহ সব"।

## প্রাসঙ্গিক যা আছে
- নিজস্ব ডোমেইন (custom domain) এই পরিকল্পনায় Release 2-এর অংশ (`docs/modules/custom-domain.md`; R1-এ শুধু wildcard subdomain)।
- ইমেইল-ঠিকানা খোলা মানে একটি mail server / ইমেইল-সেবা লাগে (MX রেকর্ড, mailbox, স্প্যাম-সুরক্ষা, SPF/DKIM/DMARC) — এটি আমরা নিজে বানাই না; একটি সেবার API দিয়ে যুক্ত হবে। কোন সেবা — মালিকের সিদ্ধান্ত (AGENTS.md: বাইরের API অনুমান করে বানানো নিষেধ)।

- "সব" মানে কি ইনবক্স পড়া (ওয়েবমেইল) ও উত্তর দেওয়াও এই প্যানেলের ভেতরে?
- কে mailbox খোলে (প্রতিষ্ঠানের admin), কাদের জন্য (শিক্ষক/কর্মী), সংখ্যা-সীমা ও দাম (প্রতিষ্ঠানের ওয়ালেট থেকে?)?
