# নিজের PC-তে ছোট AI মডেল চালানো (D164 (6), AI-P1.6)

চ্যাটবট মডেল ছাড়াও চলে। এই মডেল শুধু তৈরি করা উত্তরের ভাষা স্বাভাবিক বাংলায় সাজায়। কোনো তথ্য বাইরে যায় না, সব আপনার PC-তেই থাকে। লক করা উত্তর মডেলের কাছে পাঠানো হয় না। মডেল নতুন কোনো সংখ্যা বা ✓ যোগ করলে সেই লেখা বাদ যায়, আগের উত্তরটাই থাকে।

## ১. llama.cpp নামানো (একবার)
1. https://github.com/ggml-org/llama.cpp/releases খুলুন। সবচেয়ে নতুন release-এর `llama-...-bin-win-cpu-x64.zip` ফাইলটি নামান।
2. ফাইলটি খুলে `E:\llama` ফোল্ডারে রাখুন।

## ২. মডেল চালানো
PowerShell-এ চালান:
```
cd E:\llama
.\llama-server.exe -hf Qwen/Qwen3-1.7B-GGUF:Q8_0 --host 127.0.0.1 --port 8080 -c 4096
```
- প্রথমবার মডেলটি (প্রায় ২ GB) আপনাআপনি নেমে যাবে। পরের বার আর নামাতে হবে না।
- Qwen3-এর লাইসেন্স Apache 2.0, তাই বাণিজ্যিক ব্যবহারে বাধা নেই।
- চালু হলো কি না দেখতে ব্রাউজারে http://127.0.0.1:8080/health খুলুন। `{"status":"ok"}` দেখালে চালু হয়েছে।
- এই PowerShell জানালা খোলা রাখুন। জানালা বন্ধ করলে মডেলও বন্ধ হয়ে যাবে, তখন চ্যাটবট আগের মতো নমুনা-উত্তর দেবে।

## ৩. অ্যাপের সাথে যুক্ত করা
`api\.env`-এ এই তিনটি লাইন যোগ করুন:
```
AI_LLM_URL=http://127.0.0.1:8080
AI_LLM_MODEL=qwen3-1.7b-q8
AI_LLM_TIMEOUT=45
```
তারপর আলাদা একটি জানালায় চালান:
```
cd "E:\Projects\School Management\api"
php artisan config:clear
php artisan migrate
php artisan queue:work
```
`queue:work` চালু না থাকলে উত্তর সাজানো হবে না। তখন ২ মিনিট পর "ভাষা সাজানো হচ্ছে…" লেখাটি নিজে থেকে চলে যাবে, নমুনা-উত্তরটাই থাকবে।

## ৪. দেখা
চ্যাটে একটি প্রশ্ন করুন। প্রথমে সাথে সাথে নমুনা-উত্তর আসবে, পাশে "ভাষা সাজানো হচ্ছে…" লেখা থাকবে। কয়েক সেকেন্ড পর সাজানো উত্তর এসে সেটির জায়গা নেবে।

## ৫. দুটি মডেলের তুলনা
একই পরীক্ষা-সেট দিয়ে প্রতিটি মডেলে একবার করে চালান:
```
php artisan ai:evaluate storage/ai-eval.json --institution=<slug> --rephrase=20
```
শেষ লাইনে দেখাবে: কয়টি সাজানো উত্তর ভরসার নিয়মে পাস করেছে আর প্রতিটিতে গড়ে কত সেকেন্ড লেগেছে।

এরপর মডেল বদলে আবার একই কমান্ড চালান:
1. `llama-server` বন্ধ করে `-hf Qwen/Qwen3-4B-GGUF:Q4_K_M` দিয়ে আবার চালু করুন।
2. `.env`-এ `AI_LLM_MODEL=qwen3-4b-q4` লিখুন।
3. `php artisan config:clear` চালিয়ে আবার `ai:evaluate` কমান্ডটি চালান।

যে মডেল বেশি উত্তর পাস করায় আর সময়ও মেনে নেওয়ার মতো লাগে, সেটিই বেছে নিন। VPS নেওয়ার পর শুধু `AI_LLM_URL` বদলালেই হবে, কোডে হাত দিতে হবে না।
