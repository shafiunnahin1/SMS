> আগের প্রম্পট `owner/AGENT-PROMPT-R217-FINAL.md`-এর অনুমতি ও নিয়ম একই থাকবে। কোড, test বা docs বদলাবে না; commit বা push করবে না।

## প্রস্তুতি
- `git pull origin claude/r216-omr-d127` চালাও। HEAD এই প্রম্পট যে commit-এ এসেছে সেটি বা তার পরের হতে হবে।
- `npm run dev`, `php -S`, আর `php artisan queue:work` চালাও।
- **PDF দুটি (OMR preview, merit PDF) আগে ব্যর্থ হয়েছিল, কারণ IDM (Internet Download Manager) অনুরোধটি আটকে নিয়েছিল (`204 Intercepted`)।** এবার Chrome-এর IDM extension বন্ধ রাখো, অথবা IDM-এর exceptions-এ `127.0.0.1` আর `localhost` যোগ করো। তারপর দুটি PDF আবার চেষ্টা করো।

## ধাপ
1. **বহু-বিষয়ের পরীক্ষা:**
   - Class 10-এর exam-এ দুটি বিষয় যোগ করো। এই বিষয় দুটি প্রশ্নপত্রের দুই block-এর সঙ্গে মিলবে।
   - প্রতিটি বিষয়ে আলাদা block link করো। প্রতিটিতে শুধু নিজের block-এর MCQ নম্বর দেখাতে হবে।
2. **Unlink:** একটি বিষয়ে দুটি প্রশ্নপত্র link করো, তারপর একটি সরাও। নম্বরের ঘরগুলো বদলাতে হবে। নম্বর আছে এমন বিষয়ে unlink করতে গেলে আটকাতে হবে।
3. **OMR preview আর merit PDF:** দুটিই PDF হিসেবে খুলতে হবে।
4. **সংশোধন:**
   - শিক্ষক হিসেবে প্রকাশিত পরীক্ষার নম্বর পাতা খোলো। ঘরগুলো শুধু-পড়ার হতে হবে, Save বোতাম থাকবে না।
   - principal হিসেবে খোলো। "সংশোধন সংরক্ষণ" বোতাম থাকতে হবে। একজনের নম্বর বদলে সেভ করো।
   - তারপর পরীক্ষার SMS রিপোর্টে "সংশোধন" ১টি দেখাতে হবে। সম্মতি না থাকলে সেটি "বাদ" হিসেবে দেখাবে।
5. **SMS সম্মতিসহ:**
   - একজন শিক্ষার্থীর অভিভাবকের SMS সম্মতি UI থেকে নথিভুক্ত করো।
   - তারপর "অভিভাবকদের SMS পাঠান" চাপো। সেই একজন "পাঠানো" হতে হবে, বাকিরা "বাদ"। log-driver চালু আছে কি না নিশ্চিত হও।
6. **360px:** নম্বর এন্ট্রির পাতার স্ক্রিনশট নাও। নতুন কার্ড-লেআউট আর নিচে আটকে থাকা Save বোতাম দেখাতে হবে।

## রিপোর্ট
প্রতিটি ধাপের জন্য "ঠিক আছে / সমস্যা: …" লেখো। সঙ্গে দাও SMS রিপোর্টের সংখ্যা, নতুন `local.ERROR` লাইন, আর কনসোলের error।
