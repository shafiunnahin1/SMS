# Owner's guide (PDF)

`Release-1-Plan-bn.pdf` — the complete plan for the owner, in Bengali, for a non-technical reader (38 pages: cover + 37). Part one (sections 1-15) describes Release 1 in detail; part two (sections 16-28) covers the WHOLE product: the four institution types, every module, R0-R7, the 41 proposed features, the 143-table data model, all decisions, open owner decisions, assumed defaults and a full chapter on Release 3 (section 24) one on the coding-agent rules and the machine guard (section 25) one on the complete release, decision D45 (section 26) and one on the self-hosted edition, decision D46 (section 27) and the per-module pricing model, decision D47 (section 28).

Rebuild after ANY change to the plan:

    python3 docs/owner-guide/build_pdf.py

- Every number (tables, modules, tasks, routes, tests, decisions, checks) is read from `docs/release/r1-scope.json`, `docs/release/r1-plan.json`, `docs/database/schema.sql`,
  `docs/modules/institution-types.md`, `docs/LOCKED-DECISIONS.md` and `docs/ROADMAP.md`; nothing is typed in by hand.
- The build runs `infra/spec-verify/verify.py --deep` first and REFUSES to produce a PDF when any check fails.
- Engine: headless Chrome through Playwright (`/opt/google/chrome/chrome`), which shapes Bengali conjuncts correctly. `reportlab` is NOT used - it does not shape Bengali.
- Fonts: FreeSans / FreeSerif (the only Bengali fonts installed in the build environment; the look is plain). Bold Bengali is synthesised by the browser.
  To use another typeface (e.g. Noto Sans Bengali), install it and change the two `@font-face` lines in `build_pdf.py`.
- Part two is generated by `content_c.py` straight from `docs/ROADMAP.md`, `docs/modules/README.md`, `docs/modules/institution-types.md`, `docs/DATABASE.md`, `docs/LOCKED-DECISIONS.md` and `PRODUCT.md` through `sources.py`; only its introductions are written by hand. The build asserts that the module map shows exactly the Release 1 modules of `r1-scope.json`.
- The text lives in `content_a.py` (cover, summary, sections 1-6) and `content_b.py` (sections 7-15, glossary, appendices). Task and table descriptions are dictionaries there;
  the build fails if a table, module or task exists in the plan without a description.
- The PDF is a SNAPSHOT: it is not regenerated automatically, so rebuild it when the plan changes.
